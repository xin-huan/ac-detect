# 🚀 快速开始指南

### 步骤1：安装依赖（1分钟）

```bash
# 安装依赖
cd voice_system
pip install -r requirements.txt
```

### 步骤2：获取HuggingFace Token（2分钟）

1. 访问 https://huggingface.co/join 注册账号（免费）
2. 访问 https://huggingface.co/settings/tokens 创建token
3. 接受模型使用条款：
   - https://huggingface.co/pyannote/speaker-diarization-3.1
   - https://huggingface.co/pyannote/embedding
   -  https://huggingface.co/pyannote/segmentation-3.0
   -  https://huggingface.co/pyannote/wespeaker-voxceleb-resnet34-LM
4. 设置环境变量：
  查看.env_example文件，按照要求在.env文件中填入自己的hftoken.

### 步骤3：直接运行example/下的basic_usage.py文件
如果要新增声纹在voice_examples中，.wav格式，然后运行enroll_voiceprints.py文件，录入声纹，声纹保存在voice_database.pkl中（项目目录下一级）
同样在test.mp4同级目录支持放入其他视频


## ❓ 遇到问题？

1. 检查FFmpeg：`ffmpeg -version`
2. 检查token：确保已接受模型使用条款
