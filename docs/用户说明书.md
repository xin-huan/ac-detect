## 1. 系统概述

多维智能融合学情监测系统是一套面向课堂教学场景的多模态分析平台，融合**计算机视觉**、**语音识别**与**声纹匹配**三大技术路线，实现对课堂中学生行为、发言内容与专注度的自动化分析。

### 核心功能模块

| 模块 | 功能 |
|---|---|
| 📝 学生建档 | 录入学生人脸特征与声纹特征，建立多模态身份档案 |
| 📋 学生档案 | 统一管理已建档学生，支持查看、修改、筛选、删除 |
| 🎥 视频分析 | 上传课堂视频，自动进行行为检测、语音识别与专注度评分 |
| 📊 分析报告 | 生成课堂总体报告与每位学生的详细个人报告 |
| 📂 历史报告 | 持久化存储分析结果，支持回看与删除 |

### 技术架构

- **人脸识别**: InsightFace (buffalo_l) — 人脸检测、特征提取与身份匹配
- **行为检测**: YOLOv10 — 学生行为识别（玩手机、睡觉、站立、举手、写字、喝水等）
- **语音识别**: OpenAI Whisper (medium) — 课堂语音转文字
- **说话人分离**: pyannote.audio — 区分不同说话人
- **声纹匹配**: pyannote.audio embedding — 将说话人映射到已建档学生
- **专注度评分**: 自定义加权模型 — 综合行为与语音维度计算专注度分数

## 2. 环境准备与启动

### 2.1 创建 Conda 环境

本项目使用单一 Conda 环境 `ac_detect`，同时运行人脸、YOLO 行为检测与语音模块。

```powershell
powershell -ExecutionPolicy Bypass -File scripts\setup_env.ps1
```

或手动创建：

```bash
conda env create -f envs/ac_detect.yml
```

### 2.2 配置 HuggingFace Token

在项目根目录创建 `.env` 文件（已有 `.env.example` 模板）：

```
HF_TOKEN=你的HuggingFace令牌
HF_ENDPOINT=https://hf-mirror.com
```

> `HF_ENDPOINT` 使用国内镜像加速模型下载（Whisper、pyannote 等）。如不在中国大陆可删除此行。

### 2.3 激活环境并启动

```bash
conda activate ac_detect
python app.py
```

浏览器访问 `http://localhost:5000` 进入系统主界面。

【需启动终端截图】

### 2.4 命令行视频分析（可选）

```bash
python yolo_main_analysis.py testvideo/你的视频.mp4
```

程序完成后，结果保存在 `result` 目录下。

## 3. 学生建档

学生建档是使用系统的**前提步骤**。只有已建档的学生，才能在视频分析中被识别和评分。

### 3.1 进入建档页面

点击顶部导航栏 **📝 学生建档** 标签页。

【需学生建档页面整体截图】

### 3.2 输入学生姓名

在"学生姓名"输入框中输入学生姓名。系统会自动检测该学生是否已建档，并在下方显示状态提示：
- 📝 新学生，请录入人脸和/或声纹特征
- ✅ 该学生的人脸和声纹特征均已录入
- ⚠️ 仅录入了部分特征

【需姓名输入与状态提示截图】

### 3.3 人脸特征录入

支持两种方式录入人脸特征：

**方式一：摄像头拍照**
1. 点击 **📷 启动摄像头** 按钮
2. 系统弹出摄像头实时预览画面
3. 点击 **📸 拍摄快照** 拍照
4. 预览满意后点击 **确认并录入**，不满意可点击 **重拍**
5. 录入成功后显示 ✅ 人脸特征已录入

【需摄像头拍照流程截图（3张）：摄像头预览、拍照预览、录入成功】

**方式二：上传本地图片**
点击 **📁 或上传本地图片**，选择包含清晰人脸的图片文件，系统自动检测并提取人脸特征。

【需上传图片录入截图】

### 3.4 声纹特征录入

支持两种方式录声纹特征：

**方式一：麦克风录制**
1. 点击 **🎙️ 开始录制**，朗读 5-10 秒语音
2. 点击 **⏹️ 停止** 结束录制
3. 可点击音频播放器预览录音
4. 确认后点击 **✅ 确认并上传声纹**
5. 录入成功后显示 ✅ 声纹特征已录入

【需声纹录制流程截图（3张）：录制中、预览、录入成功】

**方式二：上传本地音频**
点击 **📂 上传本地音频文件**，支持 .wav / .mp3 / .m4a 等格式。

【需上传音频录入截图】

## 4. 学生档案管理

### 4.1 进入档案页面

点击顶部导航栏 **📋 学生档案** 标签页。

【需学生档案页面整体截图】

### 4.2 档案列表

系统以表格形式展示所有已建档学生，每行包含：
- 序号
- 学生姓名
- 人脸特征录入状态（✅ 已录入 / ❌ 未录入）
- 声纹特征录入状态（✅ 已录入 / ❌ 未录入）
- 综合录入状态标签（完整 / 仅人脸 / 仅声纹 / 未录入）

### 4.3 筛选学生

使用顶部的筛选下拉菜单，可按条件过滤：
- 全部学生
- 完整录入（人脸+声纹均有）
- 仅有人脸
- 仅有声纹
- 未录入任何特征

【需筛选功能截图】

### 4.4 修改学生信息

**方式一：点击表格行**
点击学生所在行，展开修改面板，面板顶部显示学生**头像照片**。面板内可分别管理人脸和声纹特征：

- 📷 拍照更新 — 重新拍摄人脸照片
- 📁 上传图片 — 上传新的人脸图片
- 🗑️ 删除 — 删除该特征
- 🎙️ 录制更新 — 重新录制声纹
- 📂 上传音频 — 上传新的声纹样本

【需修改面板截图（展开状态，含头像）】

**方式二：点击修改按钮**
点击行末尾的 ✏️ 修改按钮，效果同上。

### 4.5 删除学生

**单个特征删除**：在修改面板中点击对应特征的 🗑️ 删除按钮，确认后删除。

**整学生删除**：点击表格行末尾的 🗑️ 删除按钮，确认后同时删除该学生的人脸特征、声纹特征及照片。

## 5. 视频分析

### 5.1 进入分析页面

点击顶部导航栏 **🎥 视频分析** 标签页。

【需视频分析页面整体截图】

### 5.2 选择视频文件

点击 **📹 选择视频文件** 按钮，从本地选择课堂录制的视频文件（支持常见视频格式）。选择后按钮旁显示已选文件名。

【需选择视频截图】

### 5.3 开始分析

点击 **🚀 开始分析** 按钮，系统进入三阶段分析流程：

| 阶段 | 内容 | 技术模块 |
|---|---|---|
| 阶段一 | 行为检测 | YOLOv10 目标检测 + InsightFace 人脸识别 |
| 阶段二 | 语音识别 | Whisper 语音转文字 + pyannote 说话人分离 + 声纹匹配 |
| 阶段三 | 专注度评分 | 加权评分模型计算个体与群体专注度 |

进度指示器实时显示当前所处阶段，进度条动画展示整体进度。

【需分析进度截图（三个阶段各一张）】

### 5.4 分析完成

分析完成后，进度条满格，各阶段标记为绿色完成状态。报告区域自动展示分析结果。页面触发庆祝动画。

## 8. 专注度评分体系

### 8.1 评分模型

系统采用**行为加权评分模型**，对每帧检测到的学生行为赋予专注度权重：

| 行为 | 权重 | 说明 |
|---|---|---|
| 举手 (hand_up) | 0.90 | 高度专注，积极参与 |
| 写字 (write) | 0.80 | 高专注度，课堂练习 |
| 站立 (stand) | 0.70 | 中等偏上，可能回答问题 |
| 喝水 (drink) | 0.40 | 中性行为 |
| 无关联行为 | 0.30 | 未被 YOLO 检测到特定行为 |
| 玩手机 (play_phone) | 0.10 | 低专注度，分心 |
| 睡觉 (sleep) | 0.00 | 完全无专注 |

### 8.2 计算方式

- **个体专注度**：学生在所有帧中行为权重的平均值 × 100
- **群体专注度**：所有检测到学生的行为权重加权平均 × 100
- **未知行为**：默认权重 0.40（可通过 API 动态调整）

### 8.3 权重配置接口

系统提供 API 端点支持动态调整专注度权重：

| 端点 | 方法 | 说明 |
|---|---|---|
| `/api/score/defaults` | GET | 获取当前评分权重配置 |
| `/api/score/compute` | POST | 使用自定义权重重新计算 |
| `/api/score/compute-upload` | POST | 上传日志文件并用自定义权重计算 |
| `/api/score/preview` | GET | 预览已保存的评分结果 |

## 9. 附录：API 接口一览

### 人脸识别 (`/api/face`)

| 端点 | 方法 | 说明 |
|---|---|---|
| `/enroll` | POST | 录入人脸特征（上传图片 + 姓名） |
| `/names` | GET | 获取人脸库全部学生姓名 |
| `/unified_names` | GET | 获取统一学生名单（含录入状态） |
| `/delete` | POST | 删除指定学生的人脸特征 |
| `/photo/<name>` | GET | 获取学生最新人脸照片 |
| `/delete-student` | POST | 删除学生全部档案（人脸+声纹+照片） |
| `/clear` | POST | 清空人脸数据库 |

### 声纹识别 (`/api/voice`)

| 端点 | 方法 | 说明 |
|---|---|---|
| `/enroll` | POST | 录声纹特征（上传音频 + 姓名） |
| `/delete` | POST | 删除指定学生的声纹特征 |
| `/transcribe` | POST | 音频/视频转文字（含声纹匹配） |

### 视频分析 (`/api/analysis`)

| 端点 | 方法 | 说明 |
|---|---|---|
| `/analyze` | POST | 上传视频并执行完整分析流程 |
| `/history` | GET | 获取历史分析报告列表 |
| `/report/<name>` | GET | 获取指定视频的分析报告 |
| `/report/<name>` | DELETE | 删除指定视频的分析报告 |

### 专注度评分 (`/api/score`)

| 端点 | 方法 | 说明 |
|---|---|---|
| `/defaults` | GET | 获取评分权重与默认值配置 |
| `/compute` | POST | 指定日志路径执行评分计算 |
| `/compute-upload` | POST | 上传日志文件执行评分计算 |
| `/preview` | GET | 预览已保存的评分 JSON 结果 |
