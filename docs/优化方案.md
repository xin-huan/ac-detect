- **学生筛选 / 搜索**：按姓名过滤
- **排序**：按专注度分数升序/降序
- **折叠面板**：默认仅展示摘要（姓名、分数、关键指标），展开后查看行为记录与发言内容
### 5.2 行为与数据展示
- **去重与翻译**：`stand` →「起立」，`phone` →「使用手机」；同一时段多条合并为「起立 ×8」
- **时间轴联动**（若有帧时间或时间戳）：点击某条行为 → 高亮对应时间段；未来可扩展为与视频预览联动

## 七、建议实施优先级
1. **四步心智模型 + 步骤指示** — 解决流程不清晰
2. **报告 Dashboard + 学生表格/排序** — 解决难对比与「文字墙」
3. **可信等待（短期 indeterminate + 耗时）** — 解决进度不可信与等待焦虑
4. **报告交互（筛选、折叠、行为翻译聚合）** — 提升报告可读性
5. **异步任务与真实进度（中期）** — 需前后端联调
6. **导出 PDF/HTML、历史报告** — 面向教师场景完善闭环
